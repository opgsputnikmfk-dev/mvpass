Какие сочетания фильтров дают результат

Активные фильтры, базовый сценарий и вариант с Фибоначчи работают параллельно. При смене настроек начинается новая серия с отдельным капиталом. Сравнивай счета с одинаковой датой начала.

Сравнивайте варианты одной серии: они наблюдаются одновременно. Разные серии могут охватывать разные даты. При сохранении фильтров начинается новая серия; прошлая остаётся в списке.

Как понимать результаты

Прибыль — итог закрытых сделок после расходов. Просадка — самое большое снижение учебного капитала. Доля удачных сделок сама по себе не показывает доходность. При малом числе сделок вывод делать рано.

Проверка на истории

Команды lab-init и lab-run создают зафиксированный протокол, сравнивают каждый из 25 фильтров и выбранные сочетания. Финальный период открывается только после отбора.

Недоступные исторические данные отмечаются явно. Прибыль на демонстрационных свечах не является результатом рыночной проверки.

Как работает бот — пять шагов

  1. Получает графики выбранных монет с биржи.
  2. Ищет уровни, направление и подходящую ситуацию.
  3. Проверяет включённые фильтры. При нехватке данных вход блокируется.
  4. Моделирует учебный вход, стоп и цель с ограничением риска.
  5. Записывает результат и сравнивает наборы фильтров.

Все сделки учебные. Если биржа недоступна, бот не придумывает цены и сигналы.
