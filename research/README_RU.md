# Проверка стратегий AI Crypto на фьючерсах

Вторая серия: [медленные трендовые стратегии, результаты и графики](round2/RESULTS_RU.md). Код — `search_round2.py`; правила и периоды отделены от первой серии. Ниже описана первая серия.

Этот модуль реализует три семейства торговых правил и проверяет шесть заранее заданных вариантов. Это исследовательский код: подключений к торговому счёту и отправки ордеров нет.

## Данные и периоды

Публичный архив Binance USD-M Futures: `https://data.binance.vision/data/futures/um/monthly/`. BTCUSDT, ETHUSDT, SOLUSDT. Файлы минутных свечей, минутной mark price и ставок финансирования проверяются по SHA-256 биржи. Декабрь 2025 используется для прогрева индикаторов; январь–сентябрь 2026 для исследования. Проверяются полнота минут и интервалов финансирования. Архивы могут впоследствии исправляться биржей; использованные хеши записаны в `data_manifest.json`.

- Январь–апрель: результаты разработки.
- Май–июнь: выбор одного варианта среди шести. Сначала варианты с положительным итогом и минимум 30 сделками, затем максимальное отношение суммы прибыли к сумме убытков. Если подходящих нет, лучший по итогу рассматривается только диагностически.
- Июль–сентябрь: отдельный финальный период для выбранного варианта. Другие варианты по этому периоду не выбираются.

В `protocol.json` заранее записаны варианты, периоды и критерии допуска. `selection_locked.json` фиксирует выбор до расчёта финального периода. Это одна хронологическая проверка, а не полноценное исследование со множеством последовательных независимых окон.

## Правила

Все входы по закрытым 15-минутным свечам. Часовые показатели берутся только из завершённых часовых свечей.

1. **Откат по тренду.** Часовая EMA50 и цена находятся по одну сторону EMA200, EMA50 движется в сторону тренда. Предыдущая 15m-свеча коснулась EMA20, текущая прошла её максимум/минимум по тренду. Стоп за четырьмя последними свечами с запасом 0,15 ATR. Цель 1,5 или 2 расстояния до стопа.
2. **Пробой диапазона.** Тот же часовой тренд, закрытие за диапазоном предыдущих 20 или 40 свечей, объём выше среднего прошлых 20 свечей в 1,2 раза. Стоп 1,5 ATR, цель 3 ATR.
3. **Возврат к средней.** Небольшой наклон часовой EMA50. Цена возвращается внутрь полосы вокруг средней за 20 свечей после выхода из неё. Ширина 2 или 2,5 стандартных отклонения. Цель — средняя на момент сигнала, стоп 1,5 ATR.

LONG и SHORT зеркальны. Параметры не оптимизируются по финальному периоду. Проверка соседних параметров ±10% относится только к периоду выбора и не меняет победителя.

## Исполнение и деньги

Вход — через одну полную минуту после границы сигнальной свечи. Слишком большой уход цены (0,5 ATR) отменяет вход. Комиссия 0,055% за сторону — сценарий, не фактический тариф пользователя. Суммарное ухудшение цены на сторону 0,045% включает допущения о спреде и проскальзывании; стресс-сценарий — 0,09%.

Финансирование использует историческую ставку и цену открытия соответствующей минуты mark price. Это приближение к точной цене расчёта, а не точная реконструкция биржевого удержания. Внутри минуты финансирование обрабатывается перед выходами. Стоп выигрывает спор со своей целью в одной свече; при разрыве выход по худшей цене открытия. Полное закрытие по цели, стопу, через 12 часов или на границе проверяемого периода. Повторный вход по монете не ранее 30 минут после выхода.

Начальный учебный счёт 10 000 USDT. Плановый риск сделки до 0,25%, общий до 0,75%, однонаправленных до 0,35%. До трёх сделок, до двух в одну сторону. Одна позиция до 25% счёта по номиналу, весь портфель до 100%, без плеча. После потери 2% за день входы до следующего дня остановлены; после снижения от максимума на 8% новые входы остановлены до конца данного периода. Для каждого периода счёт начинается заново. Финансовый результат сверяется с полной суммой закрытых сделок.

Допуск: положительный период выбора; минимум 50 сделок в финальном периоде; отношение прибыли к убыткам от 1,15; положительный итог минимум двух месяцев из трёх; просадка ниже 8%; положительный результат при удвоенном ухудшении исполнения. Эти исследовательские пороги не гарантируют будущую доходность.

## Запуск

```sh
pip install -r requirements.txt
python -m unittest discover -s research -v
python research/research_futures.py --cache /tmp/ai_crypto_futures --output research/results.json
```

Цена загрузки — время и трафик, платные API не нужны. Сырые архивы не включены в репозиторий. Повторный запуск использует проверенный локальный кеш. В итогах показаны доходность, частота, доля прибыльных, просадка, результаты по месяцам/монетам и финансирование.

Ограничения: только три заранее выбранные крупные сохранившиеся монеты, нет исторического стакана, неопределённость порядка событий внутри минуты, ограниченная выборка рыночных режимов. Положительный результат требует дальнейшего наблюдения. Отрицательный результат является основанием отклонить проверенный вариант.
