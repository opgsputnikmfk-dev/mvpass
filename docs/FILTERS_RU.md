# Правила анализа версии 4.0

Эти определения описывают код и не заявляют доказанное преимущество.
Все индикаторы используют закрытые свечи. Значимый экстремум — уникальный
максимум/минимум среди трёх свечей слева и трёх справа; доступен только после
закрытия третьей правой свечи. Равные вершины не считаются отдельным pivot.

## Четыре сценария

| ID | Условие |
|---|---|
| `pullback` | Направление 1ч по EMA; последние пять свечей 15м пересекали зону EMA20 ±0,25 ATR; закрытие 5м выше high / ниже low трёх предыдущих свечей |
| `breakout` | Закрытие 5м впервые переходит за high/low 20 предыдущих свечей; предыдущая свеча была внутри своего канала |
| `false_break` | Текущая 5м свеча выходит тенью за 20-свечный канал и закрывается обратно внутри |
| `range_reversal` | Предыдущая 15м свеча закрылась за внешней полосой Bollinger, текущая вернулась внутрь; 5м подтверждает пробой трёх свечей |

Отсутствие сигнала означает ожидание, а не ошибку. Несколько сценариев могут
появиться одновременно; лимит одной позиции на монету и cooldown предотвращают
повторный фактический учебный вход. При конфликте используется стабильный
порядок времени, символа и ID — выбор по будущему результату исключён.

Первичный стоп для всех сценариев — за экстремумом пяти последних свечей 15м
с запасом `stop_atr_buffer × ATR14`. После моделирования входа цель пересчитывается
от фактической цены. Стоп округляется от входа, цель — к входу, с учётом tick size.

## Переключатели

| ID | Что считается прохождением |
|---|---|
| `ema` | LONG: цена 1ч выше EMA200 и EMA50 выше значения три свечи назад; SHORT зеркально |
| `structure` | Два последних подтверждённых high и low 1ч последовательно растут / падают |
| `regime` | Для отката/пробоя ADX ≥ порога; для возврата/ложного пробоя ADX ниже порога |
| `adx` | ADX14 1ч ≥ `adx_min`; не определяет направление |
| `btc` | Направление BTC 1ч по EMA совпадает со стороной; для BTC это дублирует EMA |
| `rsi` | RSI14 15м внутри диапазона, заданного отдельно для LONG/SHORT |
| `macd` | Гистограмма MACD 12/26/9 15м имеет знак стороны |
| `atr` | ATR14 15м / цена в пределах `atr_min_pct…atr_max_pct` |
| `bollinger` | Ширина полос (20,2) 15м увеличилась относительно предыдущей свечи |
| `volume` | Объём 5м / средний объём 20 предыдущих свечей ≥ `volume_min` |
| `vwap` | LONG выше / SHORT ниже VWAP с 00:00 UTC; типичная цена × объём |
| `profile` | LONG выше / SHORT ниже POC приближённого профиля 96 свечей 15м; 24 равных ценовых корзины |
| `fibonacci` | Цена внутри 38,2–61,8% последнего подтверждённого импульса стороны, допуск `fib_tolerance_atr × ATR` |
| `room` | Встречный подтверждённый уровень дальше цели и не ближе `room_r`; если впереди не найден уровень, это явно считается отсутствием найденного препятствия |
| `candle` | Поглощение тела противоположной 5м свечи либо тень ≥2 тел с закрытием в нужной половине свечи |
| `divergence` | Два подтверждённых экстремума 15м: цена обновила экстремум против стороны, RSI изменился в сторону сигнала |
| `channel` | Закрытие 5м за каналом high/low 20 предыдущих свечей |
| `double_extreme` | Два low/high 15м в пределах 0,5 ATR и закрытие за промежуточным максимумом/минимумом |
| `fvg` | Текущая 15м свеча касается незакрытого ценового разрыва между первой и третьей свечами и закрывается в сторону сигнала |
| `order_block` | Касание диапазона противоположной свечи перед импульсной свечой с телом >1,5 ATR; зона до касания не пробита |
| `oi` | Последнее изменение OI между 5м наблюдениями ≥ `oi_change_min_pct`; это фильтр участия, не прогноз стороны |
| `funding` | Ожидаемый расход стороны `side × funding_rate` ≤ `max_funding_cost` |
| `spread` | `(ask − bid) / mid × 10000` ≤ `max_spread_bps` |
| `depth` | Минимум номинальной глубины обеих сторон в пределах 0,1% от mid ≥ `min_depth_usdt` |
| `events` | Время вне всех пользовательских интервалов событий; автоматической ленты новостей нет |

`structure`, `divergence` и некоторые фигуры возвращают «нет данных», если
недостаточно подтверждённых экстремумов. Отсутствие существующего FVG / order
block означает «не пройден», а не «данные потеряны». Отсутствие снимка OI/стакана
означает «нет данных». Эти состояния различаются в журнале.

Профиль распределяет объём свечи равномерно между её low/high. Это грубое
приближение, не tick volume profile. FVG и order block — ограниченные формальные
модели, не доказательство присутствия крупных участников или их намерений.

## Фибоначчи

Для LONG берётся последний подтверждённый high и предшествующий ему
подтверждённый low; для SHORT зеркально. Проверяется правильный порядок цены.
Уровень отката: `конец − (конец − начало) × коэффициент`.
Отображаются 23,6 / 38,2 / 50 / 61,8 / 78,6%; 50% — традиционная дополнительная
линия. Автоматическое подтверждение вершины требует будущих относительно самой
вершины свечей, поэтому линия становится доступна только **после подтверждения**.
В backtest это время учитывается. Расширения для автоматического выбора цели
пока не используются: цель единая, в R, для сопоставимости экспериментов.

## Зависимость фильтров

EMA, RSI, MACD и ADX частично описывают одни и те же движения. Одновременное
прохождение не означает независимых доказательств. Некоторые сочетания
противоречивы: ADX-тренд и диапазонный сценарий; пробой канала и глубокий откат.
Все включённые фильтры соединяются логическим **И**. Веса и голосование
не применяются; количества пройденных фильтров недостаточно для оценки вероятности.

Параметры можно менять в полном JSON настроек. Нельзя изменять веса или пороги
после просмотра контрольного периода и продолжать считать его независимым.
