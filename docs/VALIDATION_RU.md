# Проверки сборки 4.0.0 — 04.11.2026

## Выполнено

- **55 автоматических тестов unittest прошли.** Команда:
  `python -m unittest discover -s tests -v`.
- LONG/SHORT, комиссии, проскальзывание, funding, разрывы цены, одновременное
  касание стопа/цели, тайм-аут, трейлинг, ограничения риска, отмена позднего входа.
- Свеча сигнала не используется для исполнения. Внутриминутная прибыль от
  закрытия не финансирует вход в начале той же минуты.
- Будущие свечи не меняют прошлые решения; расчёт на полном датасете совпадает
  с его доступным префиксом. Будущие снимки рынка не используются.
- Экстремумы доступны после подтверждения; неполные свечи исключаются.
- SQLite сохраняет кандидатов/решения/состояние; повторный цикл не дублирует
  сценарии. Перезапуск восстанавливает позиции, комиссии и правила выхода.
- Изменение настроек отменяет ожидающие входы, сохраняет правила открытых
  позиций и создаёт отдельную серию. Возврат к прежним настройкам также
  создаёт отдельную серию.
- Полный цикл сканера проверен с локальной подстановкой публичных ответов API.
  Это интеграционный тест кода, не проверка реального подключения к бирже.
- HTTP-аутентификация, запрет внешнего запуска без пароля, Host/Origin/CSRF,
  валидация конфигурации, CSV. Telegram принимает команды только владельца;
  формирование уведомления о входе проверено с подстановкой транспортного слоя.
- Протокол исследования не допускает пересекающихся периодов; изменённый
  протокол отклоняется; неудачный запуск тоже помечает период открытым.
  Искусственный датасет не может пройти отбор к holdout.
- Выполнены этапы develop/select для 28 вариантов на искусственном датасете.
  Holdout остался закрытым. Эти расчёты проверяют механизм исследования.
- Демо-сервис запущен и восстановлен из сохранённой SQLite-базы.
- JavaScript проверен `node --check`. В jsdom с настоящим локальным HTTP-сервером
  проверены обзор, 25 переключателей, вкладки, сохранение настроек с новой серией,
  разбор 25 проверок, запрос PNG и CSV. Ошибок выполнения скрипта не обнаружено.
- Графики цены с уровнями и капитала построены и визуально просмотрены.

## Не подтверждено

- Полный цикл публичного Bybit API из среды разработки: вместо JSON возвращается
  HTML о недоступности. Команда `doctor` распознаёт это и сообщает об ошибке.
- Доставка в настоящий Telegram: персональный токен для нового процесса не
  подключался; реальные сообщения не отправлялись.
- Внешний деплой, длительное наблюдение 24/7, реальная доходность и фактическое
  биржевое исполнение.
- Пиксельная проверка веб-дашборда в Chromium: бинарный браузер недоступен,
  загрузить его не удалось. Проверены DOM, действия и HTTP, но не визуальный
  рендер страниц на физических устройствах.
- Windows-запуск `.bat` не выполнялся в этой Linux-среде.

Среда проверок: Python 3.12.14, NumPy 2.3.5, pandas 2.2.3, Matplotlib 3.10.8.
Заявленный минимальный Python для проекта — 3.11; отдельной матрицы версий ОС и
интерпретаторов не выполнялось.

Эта сборка готова для изучения, настройки и учебного наблюдения. Она не содержит
подтверждённой прибыльной стратегии и не выдаёт синтетический результат за
проверку настоящего рынка.
